# Paradise Nursery

A React + Redux shopping cart app for browsing and buying plants online.

## Features
- Home landing page with a background image and Get Started call-to-action
- Plant categories with six plants in each category
- Add to cart functionality with cart badge updates
- Cart page with quantity controls, item removal, and checkout message
- About page with company details

## Run locally
```bash
npm install
npm run dev
```
